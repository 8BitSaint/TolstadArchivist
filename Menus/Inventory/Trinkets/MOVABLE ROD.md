# Text
An uncommon magic rod. When you press the button, it's supposed to be stuck in place, near unmovable by anything but incredible forces.

This one's broken however. The button is permanently pressed down, which causes the rod to be permanently stuck- but only to the last surface it touches. You can carry it around. It's kind of neat.
